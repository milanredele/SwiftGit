# COniguruma

[Oniguruma](https://github.com/kkos/oniguruma) 6.9.10 regular expression
library (BSD 2-clause, see COPYING), vendored for the TextMate grammar
highlighter. Only the core, Unicode tables and the ASCII / UTF-8 / UTF-16 /
UTF-32 encodings are included. Changes from upstream:

- `config.h` is hand-written for macOS instead of generated by `configure`.
- The Unicode data files included by `unicode.c` were moved to `*.inc`
  so the package manager doesn't compile them on their own.
